# Rayan Zaib Portfolio

A responsive, animated Next.js 14 + Tailwind CSS portfolio with custom glassmorphism styling.

## Run locally
1. Install Node.js 18.17+.
2. Open this folder in VS Code.
3. Run `npm install`
4. Run `npm run dev`
5. Visit http://localhost:3000

## Deploy to Vercel
Push this folder to a GitHub repository, import the repository at https://vercel.com/new, and deploy with the default Next.js settings.

## Personalise before publishing
- Check the AO Spicy Grill live URL in `app/page.tsx`; update it if your deployed domain differs.
- Replace the Excel Learning Hub contact link with its live URL when available.
- Review all project descriptions and service claims before publishing.
- Contact links use the known email and LinkedIn profile.
